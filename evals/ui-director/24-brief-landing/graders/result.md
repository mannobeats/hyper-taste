PASS if the first screen has a specific headline about rescheduling lessons around tide and wind (not a generic slogan), one primary action with a line beside it about the free trial or no card, and the product's own interface built in HTML as the main visual (a schedule, a tide or wind timeline, lessons moving, a text to a student) with concrete sample data (named students, times, a real-sounding harbour); and the rest of the page shows states of the product rather than a grid of icon feature cards.
FAIL if the main visual is a stock-photo slot, an illustration, gray placeholder bars or a fake chart with no data; if there are three or more feature cards with an icon on a tinted circle; if there are invented testimonials, logo walls or user counts presented as real; if any element has a dot inside a pill, uppercase tracked labels, emoji, or a violet or blue glow gradient.
Also FAIL if the first screen puts the headline and buttons in a left column and the picture in a right column, or if nothing moves to show what the product does (a playing product film, a scroll scene or something to try); fade-ins alone don't count. Also FAIL if that motion keeps moving under prefers-reduced-motion, or if the page has no pricing fact (€29 per instructor, 30 days free).
